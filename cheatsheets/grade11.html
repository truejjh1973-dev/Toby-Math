Math 11 — Formula Sheet

Pre-Calculus 11, one page. Print it, keep it, rehearse it.

Quadratics

General form$y = ax^2 + bx + c$
Vertex form$y = a(x - p)^2 + q$, vertex $(p, q)$
Quadratic formula$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$
Discriminant$D = b^2 - 4ac$
Sum of roots$x_1 + x_2 = -\dfrac{b}{a}$
Product of roots$x_1 x_2 = \dfrac{c}{a}$

Radicals & rational expressions

Rationalize$\dfrac{1}{\sqrt{a}} = \dfrac{\sqrt{a}}{a}$
Add fractions$\dfrac{a}{b} + \dfrac{c}{d} = \dfrac{ad + cb}{bd}$
Simplify$\dfrac{x^2 - 1}{x + 1} = \dfrac{(x - 1)(x + 1)}{x + 1} = x - 1$
RestrictionAny value making a denominator $= 0$ is excluded

Trigonometry

Right triangle ratios$\sin\theta = \dfrac{o}{h},\ \cos\theta = \dfrac{a}{h},\ \tan\theta = \dfrac{o}{a}$
Pythagorean$a^2 + b^2 = c^2$
Sine law$\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$
Cosine law$c^2 = a^2 + b^2 - 2ab\cos C$
Angle of elevation$\tan\theta = \dfrac{\text{opposite}}{\text{adjacent}}$

Inequalities

LinearSolve like equations; flip the sign when multiplying/dividing by a negative
QuadraticFind critical points, then test intervals on a number line
Interval notation$[a, b]$ includes ends, $(a, b)$ excludes ends
